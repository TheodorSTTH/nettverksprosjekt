# Nettverksprosjekt - Conflict-free replicated data type

## Arkitektur

### Overordnet

Vi bruker `compose.yaml` for å kjøre prosjektet.

### Frontend 
Vi har frontend under /frontend mappen i roten av prosjektet.
Vi kjører frontenden med en `Dockerfile`.
Frontenden bruker vue.

### Backend
Vi har backend under /backend mappen i roten av prosjektet.
Vi kjører backenden med en `Dockerfile`.
backenden bruker c++ med g++.
